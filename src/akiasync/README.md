# AkiAsync Optimization Plugin

Async optimization plugin based on Leaves Mixin, designed to improve server performance without changing core features.

<!-- more -->

## Features

::: tip Core Advantages
- 🚀 **Async Processing** - Moves time-consuming operations to async threads, reducing main thread load
- 🔧 **Non-invasive** - Does not change vanilla core features, maintains consistent gameplay
- 🎯 **High Compatibility** - Supports multiple server platforms
- ⚡ **Performance Boost** - Significantly improves server TPS stability
:::

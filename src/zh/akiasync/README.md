# AkiAsync 异步优化插件

基于 Leaves Mixin 实现的异步优化插件，旨在不改变核心特性的前提下提升服务端性能。

<!-- more -->

## 特性

::: tip 核心优势
- 🚀 **异步处理** - 将耗时操作移至异步线程，降低主线程负载
- 🔧 **无侵入式** - 不改变原版核心特性，保持游戏体验一致
- 🎯 **高兼容性** - 支持多种服务端
- ⚡ **性能提升** - 显著提升服务端 TPS 稳定性
:::

## 支持的服务端

| 服务端 | 支持状态 |
|--------|----------|
| Leaves | ✅ 完全支持 |
| Luminol | ✅ 完全支持 |
| LightingLuminol | ✅ 完全支持 |
| Lophine | ✅ 完全支持 |
| Mint | ✅ 完全支持 |

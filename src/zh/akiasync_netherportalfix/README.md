# Aki-Async-NetherPortalFix 地狱门修复插件

基于 NetherPortalFix 为 Luminol 环境开发的地狱门修复 Mixin 插件。

<!-- more -->

## 功能介绍

::: tip 核心功能
解决玩家通过地狱门传送后返回位置不正确的问题，确保玩家能够准确返回原来的地狱门位置。
:::

## 特性

- 🚪 **位置修复** - 修复地狱门传送后返回位置偏移的问题
- 🔗 **门户绑定** - 记录玩家进入的地狱门，确保返回时传送到正确位置
- 🌍 **多世界支持** - 支持主世界与地狱之间的双向传送修复
- 💾 **数据持久化** - 传送记录在服务器重启后依然有效

## 兼容性

| 服务端 | 支持状态 | 备注 |
|--------|----------|------|
| Luminol | ✅ 推荐 | 完全支持 |
| Leaves | ⚠️ 不需要 | 已内置修复 |
| 其他 Luminol 分支 | ✅ 支持 | 需测试 |

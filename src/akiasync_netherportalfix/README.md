# Aki-Async-NetherPortalFix

Nether portal fix Mixin plugin developed for Luminol environment based on NetherPortalFix.

<!-- more -->

## Features

::: tip Core Function
Fixes the issue where players return to incorrect positions after teleporting through nether portals, ensuring players can accurately return to their original portal location.
:::

## Highlights

- 🚪 **Position Fix** - Fixes return position offset after nether portal teleportation
- 🔗 **Portal Binding** - Records the portal players entered, ensuring correct return position
- 🌍 **Multi-world Support** - Supports bidirectional teleport fix between Overworld and Nether
- 💾 **Data Persistence** - Teleport records remain valid after server restart

## Compatibility

| Server | Support Status | Notes |

| Luminol | ✅ Recommended | Fully supported |
